# Exact-word Spanish cardinal reuse

Source-only candidate, September 7, 2026. No conversion, test, provider request,
import or runtime operation has been performed by this implementation task.

## Scope and decision

Permit only these two explicitly recorded whole-word aliases:

| Cardinal target | Existing supplemental source | Exact spoken transcript |
| --- | --- | --- |
| `es-es/acdc-cardinal-v1-number-4` | `es-es/acdc-number-4` | cuatro |
| `es-es/acdc-cardinal-v1-number-9` | `es-es/acdc-number-9` | nueve |

The existing source records report `GENERATED_QA_PASSED`, `STOP`, the same
`gemini-2.5-pro-preview-tts` model and Sulafat voice. Each transcript is exactly
the complete cardinal word required here. This does not spell a multi-digit
position digit by digit, splice a word, change language, or substitute a
different count. The source-backed numeric-label review is in
[Spanish authoring review](acdc_cardinal_es_release_review.md). Reusing a whole
word recorded as an individual telephone digit is an engineering judgment about
text/context equivalence; actual words and joined cadence still need listening.

This document approves that narrow reuse decision for independent root review.
It does not approve listening, authenticate provider provenance, approve a
complete locale or authorize runtime activation.

## Concrete importer interface

`scripts/acdc-cardinal-reuse.cjs` exports:

```javascript
const resolution = openResolution({
  cardinalDirectory, supplementalDirectory, aliasFile, aliasSha256
});
const asset = resolution.resolve('es-es', 'acdc-cardinal-v1-number-4');
// asset.master and asset.telephony are verified bytes, not trusted future paths.
// source_kind is 'reused_supplemental_master' or 'generated_cardinal'.
resolution.verifyTelephony(asset.locale, asset.id, storedTelephonyBytes);
const evidence = resolution.summary();
```

Opening verifies the original full cardinal manifest with its existing verifier
and both explicit aliases. Ordinary `QA_PASSED` entries resolve to their unchanged
generated bytes. Unknown identities, unresolved pending/failed identities and
unauthorized alias targets fail closed. The resolver reads only bounded regular
files, rejects symlinks/hardlinks and group/other-writable inputs, verifies identities and
checks manifest pins before/after resolution. It imports no authoring/provider
module and writes no files.

Reused telephony bytes are derived from the pinned 24 kHz master with the exact
existing no-dither SoX recipe and a fixed PCM16 mono 8 kHz WAV header. Both WAVs
undergo the existing technical QA. The old supplemental 8 kHz file is not used:
its historical conversion is not misrepresented as the newer deterministic
recipe. `verifyTelephony` independently resolves again and requires exact bytes;
matching duration or separately valid hashes cannot bless unrelated audio.
No trim, padding, gain adjustment, phoneme edit or fabricated silence is added.

Future cardinal-import integration is still required and is deliberately not
hidden inside the existing 210-asset importer:

`scripts/import-acdc-gemini-voices.cjs:loadPlan()` currently handles only the
fixed/completion/supplemental inventories, and `install()` caps that plan at 210.
A separate cardinal importer should consume this resolver's byte/provenance
interface. Runtime adoption would then need the new role mapping in
`applications/acdc/src/acdc_gemini_prompts.erl` and a matching finite composer
behind `acdc_language:number_prompts/2`; the current ES branch still emits SAY.
None of those production paths is changed here.

1. Use this resolver for each required cardinal role; require every role in the
   selected locale to resolve. Do not interpret a two-alias scope result as a
   complete language pack.
2. Preserve full resolution provenance and byte hashes in create-only,
   content-addressed cardinal media records; do not label reused bytes as a new
   provider request or feed them through the legacy 210-inventory size limit.
3. Independently enforce transcript/context/intro approvals. Listening evidence
   must bind a *resolved* asset-set hash containing generated and reused bytes;
   the current `pack.assetSetHash()` intentionally returns null for historical
   failed entries and must not be bypassed or falsely marked approved.
4. Integrate the finite cardinal compositor and language pack mapping only after
   complete inventory, recording/listening and playback checks. This module
   never sets runtime, deployment or full-range readiness true.

```sh

```

The fixture uses actual pinned source masters, a retained private synthetic
cardinal ledger, real deterministic SoX and negative controls. It must preserve
all original source hashes, prove no provider/file-write action by the resolver,
reject changed failure history/source/context/recipe and unrelated equal-duration
telephony, and demonstrate the ordinary generated-entry path still works.

the independent alias file hash supplied, is:
